# Interactions Audio Files Folder

Place your interaction sound effects or music files here.

### Supported File Names:
- **`click.mp3`** (or `.wav`, `.ogg`, `.m4a`): Plays whenever a button, card, choice, or tab is clicked.
- **`hold.mp3`**: Plays when a user presses and holds a topic card to trigger the tutorial.
- **`correct.mp3`**: Plays when a quiz question is answered correctly.
- **`wrong.mp3`**: Plays when a quiz question is answered incorrectly.
- **`restart.mp3`**: Plays when the topic quiz is restarted.

*Note: If no custom audio file is found, the system automatically uses a lightweight Web Audio synthesizer chime so interactions always produce clean audio feedback!*
