# Quiz / Question Mode Background Music Folder

Place your Quiz / Question mode background music file in this folder.

### Supported File Names:
- **`quiz-bgm.mp3`** (Primary default name)
- **`music.mp3`**
- **`quiz.mp3`**
- **`theme.mp3`**

### Behavior:
- **Starts playing** automatically when the user enters Quiz / Question Mode (`/questions`).
- **Loops continuously** while taking the quiz.
- **Stops immediately** when the user leaves Quiz Mode (e.g., returns to the Topic overview, Home, Artifacts, or Admin console).
- Includes an in-app Quiz Music mute/unmute toggle in the Quiz header so users can adjust or mute the sound anytime.

*Note: If no custom MP3 file is placed here yet, the app activates a gentle retro ambient synth loop so Quiz Mode has atmosphere right away, which is seamlessly replaced once you drop in your music file!*
