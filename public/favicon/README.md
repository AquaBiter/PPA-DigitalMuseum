# Favicon / Tab Icon Directory

This folder holds the browser tab icons (favicons) for the **PopPinoyArchive (PPA) Virtual Museum**.

## Files:
- `favicon.svg` - Scalable vector browser tab icon with the signature Red, Cyan, and Amber PopPinoyArchive monogram.
- Place your custom `.ico`, `.png` (16x16, 32x32, 192x192), or `.svg` files here.
- Any image placed here is accessible at `/favicon/<filename>`.
